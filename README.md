# PC Watch

Монитор нагрузки Windows без драйверов. Использует только встроенные счётчики Windows (CIM/WMI), поэтому его не блокируют «Целостность памяти», Smart App Control и блок-лист драйверов.

## Возможности
- Карточки показателей: процессор, память, диск (и свободное место на C:), видеокарта, сеть — с графиком за минуту.
- Автодиагноз: что именно тормозит систему и какое приложение виновато.
- Список приложений с иконками и понятными названиями, нагрузкой на процессор и память, подсветкой «тяжёлых».
- Снять задачу (кнопка, `Delete`, ПКМ) — завершает все процессы приложения; системные процессы защищены.
- Открыть расположение файла, поиск «что это за процесс».
- Режим администратора одной кнопкой.
- Лог в CSV.

## Запуск
1. Скачать `PCWatch.ps1` и `PCWatch.bat` в одну папку.
2. Запустить `PCWatch.bat`.

Если Windows блокирует скачанные файлы, в PowerShell в этой папке:
```powershell
Get-ChildItem | Unblock-File
```

## Требования
Windows 10/11, Windows PowerShell 5.1 (встроен). Установка и права администратора не нужны.

> `PCWatch.ps1` должен оставаться в UTF-8 **с BOM**, иначе PowerShell 5.1 испортит кириллицу.
