# PCWatch 2.0

Современный монитор производительности и отзывчивости Windows 10/11. Помогает понять, **почему компьютер тормозит**, а не просто показывает загрузку ЦП.

Программа работает без собственного драйвера, службы и установки. Основной режим доступен обычному пользователю; расширенная ETW-диагностика DPC/ISR запускается отдельно от имени администратора.

![PCWatch — Graphite Pro](docs/images/dashboard.png)

## Возможности

- **Graphite Pro:** тёмный адаптивный интерфейс WPF, живые графики, индекс здоровья системы, понятные статусы.
- **Ресурсы:** ЦП по ядрам, оценка текущей частоты, память, commit, файл подкачки, диски, GPU, сеть, схема питания.
- **Диагностика:** устойчивые отклонения, а не случайные пики; связывает нагрузку памяти и чтение страниц, активность и задержки диска, частоту и нагрузку ЦП.
- **Процессы:** PID, ЦП, память, диск, GPU, page faults, состояние и количество окон, поиск и сортировка.
- **Настоящие иконки:** извлекаются из исполняемого файла; для труднодоступных процессов используются App Paths, известные каталоги и версионные пути установки.
- **Управление окнами:** открытие приложения, список его видимых окон, восстановление свёрнутого и вывод выбранного окна на передний план.
- **Оптимизация:** обоснованные кандидаты на закрытие с устойчивыми средними метриками, последствиями, оценкой памяти и списком исключений ([скриншот](docs/images/recommendations.png)).
- **Безопасное управление:** расположение и свойства файла, поиск процесса вручную, завершение после подтверждения, защита критических процессов и проверка `StartTime` перед завершением PID.
- **Расширенный ETW-анализ:** DPC/ISR, рейтинг драйверов, оценка задержки планировщика, hard page faults за 60 секунд.
- **Отчёты:** русские заключения, доказательства и рекомендации; экспорт HTML/TXT и копирование в буфер обмена.
- **Предупреждения:** настраиваемые пороги, время удержания и защита от повторных срабатываний.
- **Emergency Mode:** `Ctrl+Alt+F12` открывает аварийный список процессов. Никаких автоматических пауз и завершений.
- **Фоновая работа:** системный трей, замедление опроса в 5 раз при сворачивании, необязательный автозапуск и CSV-журнал.
- **Диски:** анализ фрагментации только по запросу; на SSD проверка пропускается.

## Запуск portable-версии

1. Скачайте `PCWatch-2.0.0-win.zip` из GitHub Releases и распакуйте в отдельную папку.
2. Запустите `PCWatch.exe`.
3. Для ETW-анализа выберите **«Режим администратора»** в приложении.

Требуется **Windows 10/11 и .NET Framework 4.8**. В поддерживаемых Windows он уже встроен. Скачивание .NET, драйверов и дополнительных программ не требуется. Файлы TraceEvent и его зависимости входят в ZIP.

Открыть список окон конкретного процесса можно из таблицы или сразу через параметр запуска:

```bat
PCWatch.exe --windows 1234
```

Здесь `1234` — PID нужного процесса.

> Сборка не подписана код signing-сертификатом, поэтому SmartScreen может показать стандартное предупреждение для неизвестного издателя. Скачивайте файлы только из официального репозитория. При необходимости после скачивания: `Get-ChildItem -Recurse | Unblock-File`.

## Сборка из исходников

На компьютере нужны Windows, .NET Framework 4.8 и MSBuild. Запустите:

```bat
PCWatch.bat
```

Или вручную:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

`build.ps1` скачивает NuGet и зависимости только в локальные `.tools/` и `packages/`, собирает Release, выполняет тесты и создаёт:

- `artifacts/release/PCWatch/` — portable-папка;
- `artifacts/release/PCWatch-2.0.0-win.zip` — архив;
- `PCWatch-2.0.0-win.zip.sha256` — SHA-256.

Пропуск проверок при отладке:

```powershell
.\build.ps1 -SkipTests -SkipSmoke -NoPackage
```

## Тесты

- `PCWatch.Core.Tests` — 59 проверок: диагностика, алерты, рекомендации, identity/PID reuse, защита процессов и вспомогательные структуры.
- `PCWatch.CollectorSmoke` — реальные PDH-замеры, процессы, ядра ЦП, память, окна и resolver известных приложений.
- `PCWatch.EtwSmoke` — короткий ETW-замер с реальными DPC/ISR; требует отдельного запуска администратором.
- GitHub Actions собирает проект и выполняет обе проверки на Windows.

## Данные и приватность

- Быстрые метрики собираются через английские, не зависящие от языка системы **PDH**-счётчики.
- Медленные данные оборудования кэшируются; температура проверяется редко через системный WMI-датчик.
- ETW-сеанс создаётся только вручную на 60 секунд, с уникальным именем и без перехвата `NT Kernel Logger`.
- Нет телеметрии и фоновой отправки данных.
- Настройки: `%LOCALAPPDATA%\PCWatch\settings.json`.
- CSV: `%LOCALAPPDATA%\PCWatch\Logs\`.
- Отчёт сохраняется только по явной команде пользователя.

## Ограничения измерений

- Температура ЦП отображается только если Windows предоставляет поддерживаемый датчик. Иначе показывается **«н/д»**.
- Частота ЦП оценивается по `% Processor Performance` относительно номинальной частоты; это не прямой MSR-замер.
- `Page Reads/sec` и общие `Page Faults/sec` не подменяются выдуманными hard faults. Точные события hard fault собираются в ETW-анализе.
- Задержка планировщика по `ReadyThread/CSwitch` — приближённая метрика, а не универсальный показатель производительности.
- Точные SMI/BIOS-замеры без низкоуровневого драйвера не выполняются.
- Атрибуция DPC/ISR указывает образ, содержащий callback routine; это не всегда доказывает, что именно данный драйвер стал первопричиной нагрузки.

## Структура

```text
src/PCWatch/             WPF, темы, ViewModel, ETW, трей и горячие клавиши
src/PCWatch.Core/        PDH/CIM, модели, диагностика, алерты, отчёты
tests/                   Автономные и платформенные проверки
legacy/                  Исходная PowerShell-версия для справки
docs/                    Архитектура и исследование
build.ps1                Восстановление, сборка, тесты и portable ZIP
```

PCWatch 2.0 использует оригинальный интерфейс и реализацию. Код, драйверы и ресурсы WhySoSlow не входят в проект.
