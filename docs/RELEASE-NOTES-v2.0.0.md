# PCWatch 2.0.0

Полное обновление PCWatch: от PowerShell/WinForms до современного C# WPF-приложения с оригинальной темой Graphite Pro.

## Основное

- Адаптивный тёмный интерфейс, живые графики, индекс здоровья, русские пояснения.
- Процессор, ядра, частота, память, commit/pagefile, диски, GPU, сеть и схема питания.
- Устойчивая диагностика причин замедления без реакции на одиночные пики.
- Полный список экземпляров процессов: PDH-дубликаты корректно нумеруются и не затираются.
- Реальные иконки из исполняемых файлов, App Paths и версионных каталогов установки.
- Видимые окна процессов: список, состояние, открытие приложения и активация выбранного окна.
- CLI: `PCWatch.exe --windows <PID>`.
- Страница «Оптимизация»: обоснованные рекомендации с последствиями закрытия и оценкой памяти.
- Исключены активные окна, игры, VM, разработка, синхронизация, устройства и критические сервисы.
- Ручной Emergency Mode по `Ctrl+Alt+F12`, без автоматического завершения или паузы процессов.
- Проверка `StartTime` перед завершением защищает от повторного использования PID.
- HTML/TXT-отчёты, CSV, предупреждения, системный трей и настройки автозапуска.
- ETW-диагностика DPC/ISR, драйверов, dispatch latency и hard page faults по запросу администратора.

## Оптимизация

- Locale-independent PDH вместо постоянного перебора CIM.
- Кэширование медленных данных, иконок и метаданных процессов.
- Обновление строк только при изменении значений.
- Разные интервалы для карточек, таблицы, сортировки, диагностики и рекомендаций.
- Замедление сбора в пять раз при сворачивании в трей.
- На текущем тестовом ПК с 300+ процессами собственный расход после оптимизации составил около 1,4% общего CPU; результат зависит от системы и нагрузки.

## Проверено

- 59 автономных unit-проверок.
- Реальный collector smoke-test: сотни процессов, окна, память, ядра, диски, GPU и сеть.
- Release-сборка классическим MSBuild из .NET Framework 4.8.
- Обычный запуск portable-приложения, страницы, реальные иконки и список окон через UI Automation/Win32.
- ZIP: 35 файлов, CRC без ошибок, отдельный SHA-256.

## Ограничение проверки

Реальный elevated ETW smoke-test не был завершён: запуск с повышением прав отменён пользователем на UAC. ETW-код включён в сборку, но перед использованием результатов как эталонных следует повторить короткий тест от администратора.

## Установка

1. Распакуйте `PCWatch-2.0.0-win.zip`.
2. Запустите `PCWatch.exe` на Windows 10/11 с .NET Framework 4.8.
3. Для ETW выберите запуск от администратора.

Старые PowerShell-файлы сохранены в `legacy/`. Собственный драйвер и служба не требуются.
