# Очистка диска PCWatch

Собственная очистка внутри PCWatch вдохновлена категориями [krezio/roomy](https://github.com/krezio/roomy) и адаптирована под C# 5 / .NET Framework 4.8. Roomy не входит в пакет и не запускается.

## Принцип безопасности

1. Сканирование только читает файлы. Удаление начинается только после выбора элементов и отдельного подтверждения.
2. Пользовательские и системные корни запрещены для очистки: весь профиль, Documents, Desktop, Pictures, Videos, Music, Downloads, Windows, Program Files и ProgramData.
3. Reparse point, junction и symlink не проходятся. Путь проверяется через Win32 handle и конечное расположение.
4. Занятые файлы не удаляются принудительно — они пропускаются и попадают в статистику ошибок.
5. Корни Temp/cache не удаляются целиком. Файлы отбираются по типу категории и возрасту.
6. Загрузки по умолчанию идут в Корзину. Кэши удаляются безвозвратно после предупреждения. `FOF_NOCONFIRMATION` не используется, поэтому Windows не может молча согласиться на permanent delete вместо корзины.
7. Сканируется только канонический `%LOCALAPPDATA%\Temp`, а не произвольный путь из `TMP`/`TEMP`.
8. Автоматической фоновой очистки нет.

## Категории

- **Безопасно по умолчанию:** пользовательский Temp старше суток, кэши браузеров, кэши Discord/Slack/Teams/Spotify/VS Code/лаунчеров, npm/pip/Yarn/NuGet, дампы приложений и WER.
- **По решению, по умолчанию выключено:** shader cache GPU, остатки Windows Update (администратор), старые установщики, крупные загрузки и содержимое Корзины.
- **Только вручную:** `Windows.old` открывает `cleanmgr.exe`; гибернация переключается через `powercfg` с возможностью включить обратно.

Пароли, история браузера, вкладки, настройки, загрузки игр и личные документы не затрагиваются. Службы Windows не останавливаются. Если файл занят, очистка продолжится без него.

## Сознательно исключено

- Эвристическое удаление AppData-папок «оставшихся программ».
- Автоматическое удаление Steam-игр.
- Перемещение/удаление `Windows.old` напрямую.
- Очистка всего Temp или целых пользовательских каталогов.
- Постоянная фоновая очистка.
