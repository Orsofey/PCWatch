# PCWatch 2.2.0

PCWatch 2.2 добавляет полноценное управление автозапуском Windows с резервным восстановлением.

## Автозапуск

- Сканирование `Run`/`RunOnce` в HKCU и HKLM, 32/64-bit.
- Пользовательская и общая папки Startup, разрешение `.lnk`.
- Автоматические службы без kernel/file-system drivers.
- Задачи планировщика с Boot/Logon-триггерами.
- Поиск по имени, команде, издателю и расположению.
- Фильтр «Только отключённые».
- Выбор нескольких или всех доступных записей, отключение и восстановление.
- Показ издателя и статуса Authenticode.
- Открытие regedit, services.msc, taskschd.msc или расположения файла.

## Защита

- Перед изменением создаётся резервная копия в `%LOCALAPPDATA%\PCWatch`.
- Отключённые файлы Startup сохраняются и могут быть восстановлены.
- Текущие процессы и службы не завершаются.
- HKLM, службы и системные задачи требуют администратора.
- Критические службы Windows и задачи Microsoft защищены от изменения.
- Нет автоматического отключения без выбора и подтверждения.
- Операции выполняются только с выбранными элементами.

## Команды

```bat
PCWatch.exe --startup
```

Открывает страницу автозапуска и выполняет read-only сканирование. Ничего не отключается автоматически.

## Проверено

- **88 unit-проверок**, включая отключение/восстановление Run-значения, файла Startup, сохранение резервной копии, защиту критической службы, сканирование Boot/Logon-задач планировщика и защиту backup от повреждения.
- Реальный скан автозапуска на текущем ПК.
- CI GitHub Actions и portable Release.

## Ограничение

Повышенный ETW smoke-test не завершён из-за отмены UAC. UWP startup tasks могут отображаться не во всех случаях.

## Установка

Распакуйте `PCWatch-2.2.0-win.zip`, запустите `PCWatch.exe`. Для HKLM, служб, Windows Update и ETW используйте режим администратора.
