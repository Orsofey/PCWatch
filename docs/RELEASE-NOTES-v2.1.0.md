# PCWatch 2.1.0

PCWatch 2.1 добавляет собственную **безопасную очистку диска** внутри приложения. Внешний Roomy не требуется: модель категорий и handle-based защита адаптированы из [krezio/roomy](https://github.com/krezio/roomy) по MIT.

## Очистка диска

- Read-only сканирование: ничего не удаляется до выбора и подтверждения.
- Пользовательский Temp старше суток, кэши Chrome/Edge/Brave/Vivaldi/Firefox/Opera, Discord/Slack/Teams/Spotify/VS Code и игровых лаунчеров.
- Кэши npm, pip, Yarn и NuGet, дампы приложений и Windows Error Reporting.
- Shader cache NVIDIA/AMD/Intel/DirectX/Steam — по умолчанию выключен, с предупреждением о повторной компиляции.
- Остатки Windows Update, Delivery Optimization, Windows Temp и системные дампы — только от администратора и по отдельному выбору.
- Старые установщики и крупные загрузки — по умолчанию не выбраны и отправляются в Корзину.
- Очистка Корзины — отдельный необязательный пункт.
- `Windows.old` открывается через штатную `cleanmgr.exe`, без самостоятельного удаления PCWatch.
- Гибернация управляется через `powercfg`, с возможностью включить обратно.
- `PCWatch.exe --cleanup` открывает страницу очистки и запускает read-only сканирование.

## Защита

- Canonical paths через Win32 handles, запрет junction/symlink/reparse point.
- Запрет очистки личных и системных корней и всего диска.
- Занятые файлы пропускаются, а не принудительно разблокируются.
- Удаляются только выбранные пути; корни Temp/cache не стираются целиком.
- Никакой автоматической фоновой очистки.
- Не удаляются эвристические AppData-остатки и Steam-игры.

## Уже входит в PCWatch

- WPF Graphite Pro, мониторинг CPU/RAM/дисков/GPU/сети и отзывчивости.
- Реальные иконки процессов, все экземпляры Chrome/Discord, поиск и управление окнами.
- Рекомендации по безопасному закрытию фоновых программ.
- ETW DPC/ISR, отчёты HTML/TXT, CSV, уведомления, Emergency Mode и трей.
- Защита от PID reuse при завершении процессов.

## Проверено

- **71 unit-проверка**, включая старые/новые файлы, защиту корней и System32, занятые файлы, junction и отмену.
- Реальный collector smoke-test.
- Read-only сканирование очистки и отображение категорий/размеров/путей.
- Portable Release и CI GitHub Actions.

## Ограничение проверки

Повышенный ETW smoke-test не был завершён из-за отмены UAC. Код ETW включён, race при отмене исправлен, но реальный замер следует повторить от администратора.

## Установка

1. Распакуйте `PCWatch-2.1.0-win.zip`.
2. Запустите `PCWatch.exe` на Windows 10/11 с .NET Framework 4.8.
3. Для Windows Update/ETW выберите режим администратора.

Собственный драйвер, служба, .NET 10 и Roomy не требуются. Старые PowerShell-файлы сохранены в `legacy/`.
