# Управление автозапуском PCWatch

PCWatch сканирует четыре источника:

- `HKCU`/`HKLM` → `Software\Microsoft\Windows\CurrentVersion\Run` и `RunOnce`, включая 32- и 64-битные представления HKLM.
- Пользовательскую и общую папки `Startup`; `.lnk` разрешается через Windows Shell.
- Службы с автоматическим запуском, кроме kernel/file-system drivers.
- Задачи планировщика с `BootTrigger` или `LogonTrigger`.

## Безопасность

- Сканирование только читает данные.
- Отключение выполняется только для выбранных пользователем записей после подтверждения.
- Перед изменением создаётся резервная копия: `%LOCALAPPDATA%\PCWatch\startup-backup.json`, файлы Startup — в `%LOCALAPPDATA%\PCWatch\Files`. Запись backup атомарна, предыдущая копия сохраняется в `startup-backup.previous.json`; повреждение копии останавливает операции.
- Восстановление доступно на той же странице и после перезапуска PCWatch.
- Текущие процессы и службы не завершаются. Меняется только будущий автозапуск.
- Критические службы Windows, записи Microsoft и системные задачи `\Microsoft\Windows\...` защищены от изменения.
- Для HKLM, служб и системных задач нужен режим администратора.
- Нет автоматического «отключить всё» без выбора и подтверждения.

## Как отключить всё лишнее

1. Нажмите «Сканировать».
2. Изучите издателя, команду и расположение.
3. При необходимости используйте поиск и «Только отключённые».
4. «Выбрать всё доступное» выбирает только незащищённые видимые элементы.
5. Нажмите «Отключить автозапуск» и подтвердите.
6. Для возврата выберите отключённые записи и нажмите «Восстановить».

## Ограничения

- UWP startup tasks, зарегистрированные Windows Store, могут не отображаться отдельно.
- Отключение службы не останавливает уже работающий экземпляр.
- Некоторые задачи и службы могут требовать администратора даже при отсутствии отметки «Админ»; ошибка будет показана в статусе.
- PCWatch не удаляет приложение и не очищает его настройки — только запись автозапуска.

Запуск страницы со сканированием без изменений:

```bat
PCWatch.exe --startup
```
